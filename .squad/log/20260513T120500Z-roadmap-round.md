## Race Condition Incident

**Timestamp:** During parallel execution of Sage #57 and Iris #59

**What happened:** Both agents ran in same working tree; Iris's branch (squad/59) picked up Sage's commit (from squad/57) via shared git state. Iris's PR #63 would have included Sage's README changes.

**Coordinator resolution:** Rebased squad/59 to drop duplicate before merge. Final PR #63 contains only Iris's PERMISSIONS.md changes.

**Impact:** None — all PRs merged correctly after rebase. No conflicts, clean linear history.

**Root cause:** Parallel agents in same working tree inherit git state from each other. Each agent pulls main, creates branch, then pushes PR — if multiple agents are in flight, their branches can pick up each other's commits mid-work.

**Mitigation (documented for future):** Use git worktrees to isolate agent working trees (per .squad/templates/coordinator/squad.agent.md → Worktree Lifecycle Management).
